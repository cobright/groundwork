v0.17 — 포터블 배포(설치 없이 행정망 실행) 준비
- 목표: 행정망처럼 설치가 어려운 PC에서 '설치 없이' 실행.
  인터넷 PC에서 포터블 폴더를 한 번 만들고 → 행정망으로 폴더 반입 →
  '실행.bat' 더블클릭으로 구동(파이썬을 시스템에 설치하지 않음).
- 코드 포터블화:
  · 모든 경로가 파일 위치(__file__) 기준 → 폴더째 옮겨도 동작
  · .env 를 backend 폴더 기준으로 로드(작업 위치 무관)
  · uvicorn[standard] → uvicorn(+h11)로 변경: 컴파일 확장 최소화(임베디드 파이썬 친화)
  · backend/run.py 추가: 더블클릭/임의 위치에서도 서버 기동 + 브라우저 자동 열기
- 폴더 선택창 강화: tkinter 가 없는 임베디드 파이썬에서도 작동하도록
  윈도우 PowerShell 폴더 대화상자로 자동 폴백(둘 다 안되면 직접 입력 안내)
- portable\ 폴더 제공:
  · 포터블_만들기.bat : 인터넷 PC에서 한 번 실행(파이썬 임베디드+패키지 담기)
  · _build_portable.ps1 : 실제 조립 스크립트(파이썬 3.11 임베디드 기준)
  · 실행.bat : 포터블 폴더 안에서 워크벤치를 켜는 런처
  · 사용설명.txt : 1)만들기 → 2)반입 → 3)실행 안내
- 이 압축에는 미리 빌드된 frontend\dist 가 포함되어 행정망에 Node 가 필요 없습니다.

주의(정직한 한계):
  · 포터블 '조립'은 윈도우에서 실행됩니다. 리눅스에서 만든 개발자 환경에서는
    최종 조립을 대신 만들 수 없어, 인터넷 되는 윈도우 PC에서 1회 실행이 필요합니다.
  · AI 분석/검토는 외부 서비스 연결이 필요하므로 인터넷이 없는 행정망에서는
    동작하지 않습니다(나머지 기능은 정상).
