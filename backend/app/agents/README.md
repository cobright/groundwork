# agents / — 검토 서브에이전트 (네 관점)

검토자는 본문을 직접 고치지 않는다. 각자 자기 관점에서 문제를 발견해
'검토의견'만 낸다(review_opinions 표). 반영은 사용자가 결정한다.
서로 다른 검토자는 컨텍스트를 공유하지 않는다(격리).

- fact_check.py  사실확인 : 본문↔확정근거 정합성. 목차별만.
- technical.py   기술검토 : 실행 가능성(사업비·인허가·일정·운영). 전문판단은 '확인 필요'로 한계 명시.
- structure.py   구조검토 : 논리 연결(문제-원인-대안-권고), 중복·누락. 문서 전체에서 제값.
- critique.py    비평     : 다른 입장(군수/예산/사업부서/평가위원/의회)에서 약점 지적.

범위: 사실확인은 목차별. 기술·구조·비평은 목차별과 문서 전체 모두 가능.
common.py 가 JSON 파싱·정규화·문서조립을 공용으로 제공한다.
