# 호환 서버 — 회사가 아니라 주소를 고르는 네 번째 공급자

> 2026-10-01. `providers/compat_provider.py` · `services/aiconfig.py` 의 `PROVIDERS`·`base_url()`
> · `routers/setup.py` · `frontend/src/SettingsModal.jsx`.

## 왜 생겼나

2026년 공공 AI 대전환 챌린지(행정안전부·NIA) 참가안내서를 읽다가 나왔다. 두 군데가 걸렸다.

- 세션2 평가 **확산 용이성 30점**: "특정 모델(LLM)에 종속되지 않는 구조 등 타 기관 이식 용이성".
- 제출 **양식2 구동안내서**에 아예 칸이 있다 — "LLM 연결 설정: 어떤 모델을 어디에 연결하는지,
  교체 방법, 키 입력 위치 기술 (공통기반 지원 모델 구동을 시연하여 이식성을 입증할 경우 그 구동 방법 포함)".

워크벤치는 이미 OpenAI·Claude·Gemini 를 등급별로 갈아끼운다. 그래서 "2종 이상 모델에서
정상 구동"은 이미 됐다. 못 하는 것은 **행정안전부 AI 공통기반이 지원하는 모델**
(젬마·라마·GPT-OSS·엑사원·하이퍼클로바X·솔라)의 구동이었다. `openai_provider.py` 의
주소가 `URL = "https://api.openai.com/v1"` 로 못박혀 있었기 때문이다.

## 고른 길과 버린 길

공통기반 모델은 대개 OpenAI 호환 `/v1/chat/completions` 를 내준다. 그래서 **OpenAI 칸의
주소만 설정값으로 빼는** 작은 길이 있었다. 버렸다.

> 그 길을 가면 초고·검토 결과에 쓴 모델로 **"OpenAI · exaone-4.0-32b"** 가 찍힌다.
> 실패해도 다른 회사로 몰래 넘기지 않는 것과 **같은 이유**다 — 결과에 찍힌 이름이
> 거짓이 되는 순간, 그 기록으로는 아무것도 확인할 수 없다.

그래서 칸을 따로 뒀다. 이름은 **호환 서버**(`compat`). 회사 이름이 아닌 것이 맞다 —
고르는 것이 회사가 아니라 주소이기 때문이다.

## OpenAI 어댑터와 실제로 다른 네 가지

`compat_provider.py` 가 `openai_provider.py` 의 복사본처럼 보이지만, 이 네 가지가 다르다.
하나라도 빼면 실제 서버에서 깨진다.

| | OpenAI | 호환 서버 | 왜 |
|---|---|---|---|
| 주소 | 상수 | `COMPAT_BASE_URL` | 없으면 `base.no_base()` — 키가 아니라 주소부터 넣으라고 말한다 |
| 출력 한도 | `max_completion_tokens` | `max_tokens` | vLLM·Ollama 류는 앞의 이름을 모른다 |
| 키 | 필수 | **없을 수 있다** | 기관 내부망 서버는 인증이 없는 경우가 있다. 빈 `Bearer` 를 401 로 되돌리는 서버가 있어 헤더를 아예 뺀다 |
| 모델 목록 | `^(gpt-\|o\d\|chatgpt-)` 로 거름 | 이름으로 거르지 않음 | 기관이 올린 이름은 그 꼴이 아니다(임베딩류만 뺀다) |

## 추천 모델을 두지 않는다

`RECOMMENDED["compat"]` 는 세 등급 모두 빈 문자열이다. 기관마다 올려 둔 모델이 다르므로
짐작할 수 없다. 짐작해 넣으면 부를 때마다 "모델을 찾지 못했습니다"가 되는데, 화면에는
**'추천값'** 이라고 적혀 있으니 담당자는 어디가 틀렸는지 알 수 없다. 그래서

- `resolve()` 는 추천값이 빈 공급자에 `model_source = "없음"` 을 돌려준다(`"추천값"` 이라 하지 않는다).
- 모델 칸의 안내문이 `"모델 이름을 적어 주세요 (추천값이 없습니다)"` 로 바뀐다.
- `complete()` 는 모델이 없으면 **설정의 '목록' 으로 불러와 고르라**고 알려주고 멈춘다.

## 화면에서 지킨 것

- 주소도 **화면 값이 `.env` 를 이기고**, 어느 쪽에서 온 값인지 적는다(키와 같은 규칙).
- 다만 주소는 키와 달리 **되읽어 입력칸에 채운다**. 가릴 것이 없고, 눈으로 확인해야 하는 값이다.
  대신 '빈 칸 = 그대로 두기'를 쓸 수 없으므로(빈 주소도 뜻이 있다) **달라졌을 때만** 보낸다.
- 키를 쓰지 않는 공급자에게 "키가 없습니다"라고 경고하지 않는다(`key_optional`). 거짓말이 된다.
  대신 주소가 없으면 주소가 없다고 한다.
- 작업 화면 네 곳(`DraftRoom`·`LibraryRoom`·`ResourceRoom`·`ReviewRoom`)이 각자 하드코딩하던
  회사 목록을 `api.js` 의 `PROVIDERS` 한 곳으로 모았다. 넷이 각자 가지고 있으면 공급자를
  더할 때 한 화면만 고쳐지고 나머지는 모르는 상태가 된다.

## 남은 것

- 실제 공통기반 서버에 붙여 본 적이 **없다**. 주소·키·모델 이름의 생김새와 `max_tokens` 는
  OpenAI 호환 서버 일반의 규약을 따랐을 뿐이다. 실물에 한 번 붙여 보고 안 되는 것부터 고친다
  (기관 고유 양식을 넓히는 것과 같은 원칙 — 추측으로 넓히지 않는다).
- 스트리밍·도구호출은 다루지 않는다. 워크벤치가 쓰지 않는다.
