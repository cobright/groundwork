## 순서와 볼 것

| 단계 | 화면 | 이번에 처음 실물로 써 보는 것 |
|---|---|---|
| 1 | 목차 편집 → 가이드라인에서 만들기 | 배점이 카드에 실리는가(→ 최종본의 배점 지도가 이것을 읽는다) |
| 2 | 자료요청 → 부서별 발송 → 회신 파일 등록 | 요청의 목차가 맞게 붙어 있는가(채택이 이 목차로 잇는다) |
| 3 | 자료·근거 → AI 분석 → **주장 후보 → 고른 것 근거로 채택** | 후보의 인용이 '원문에 있음'인가 · 표 한 줄 인용이 열을 제대로 말하는가 · 인용보다 더 말하는 주장이 있는가 |
| 4 | 초고 → 생성 → 반영·고치기 | 근거 점검 의견이 맞는가(헛경보면 그 문장을 적는다) · 본문 출처 표시 |
| 5 | 검토 → 사실확인 | 중대·중요 의견을 '반영안함'으로 닫을 때 사유를 메모에 |
| 6 | 최종본 → 점검 | 배점 지도 · '같은 지표가 다른 값' · 인용이 원문에 없는 근거 |
